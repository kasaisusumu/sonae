# 私のマニュアル「そなえ」さん — 本番とテスト環境の差分（エンジニア向け）

「今この時点で」本番（`sonae` / `main`）とテスト環境（`sonae-test` / `test`）に
どんな違いがあるかだけを記録するドキュメントです。恒久的な仕様・作り方は
`機能仕様_テスト環境_エンジニア向け.md` と `テスト環境構築手順.md` を参照してください。

> **メンテナンス方針**: コード・環境変数・インフラ設定のいずれかで本番とテストに
> 差が生まれたとき、あるいは差が解消されたときは、**その変更と同じコミットで**
> このファイルを更新すること。「恒久的にこうなっている」ことではなく「今どう違うか」
> だけを書く（恒久的な仕組みは `機能仕様_テスト環境_エンジニア向け.md` 側に書く）。
> このファイルはそのつど書き換える差分メモなので、特定の日付を見出しに固定しない
> （「今の時点」が常に最新の内容になるようにする）。

> **このアプリ全体を判断したい場合**: この資料は「今の差分」だけを追った狭い目的の
> メモです。機能の全体像・現状の制限・運用体制まで含めた完全な説明は
> `機能仕様_エンジニア向け.md`（特に §0 と §13）と、ユーザー視点の `機能仕様_ユーザー向け.md`
> （特に §12）を参照してください。

  `buildChecklistForEvent`/`generateAndSaveChecklist`/`ensureChecklistForEvent` に

  作る（`allowAiGeneration` は既定の `true` のまま。ユーザー指定で、自動生成だけを対象にした）。
  本番は今もすべての生成経路でAIフォールバックが働く。
