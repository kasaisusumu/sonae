## 現在の状態（最新の変更を反映。日付では管理しない）

**テスト環境だけ、機能そのものが本番と違います**（本番へ昇格するまでの間）:

- テスト環境には「未来の自分へ」という新しい機能があります。予定に関係なく思い出したい
  ことを書いておくと、キーワード・ジャンル・カテゴリが一致する予定が入ったときに
  自動で知らせてくれます。予定が終わったら、その内容を次回に向けて育てられます。
- 一方、本番にある「失敗ログ」（うっかりミスの記録・先回り警告・節約額の表示）は
  テスト環境からは無くなっています。

置き場所の違いは以下のとおりです:

- リンクが違う
  - 本番: `https://sonae-teal.vercel.app`
  - テスト環境: `https://sonae-test.vercel.app`
- データが別（テスト環境で何をしても本番のデータは変わりません）
- テスト環境は検索エンジンに出ません
- テスト環境では、**時間で自動的に届く通知がすべて届きません**（新しい予定が入ったときの
  お知らせ、準備項目の「◯分前」通知、リスト全体のリマインド、予定が終わったあとの
  「メッセージを更新しませんか？」の通知）。これらは5分おきの定期チェックが届いた
  タイミングで送られる仕組みですが、その定期チェックがテスト環境には向いていないためです。
  新しい予定の取り込み自体は、アプリを開くか「カレンダーから取り込む」ボタンを押せば
  その場で反映されます（通知だけが届かない、という違いです）。
